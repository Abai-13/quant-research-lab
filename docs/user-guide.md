# 2026-10-31 版本操作提示

从首页开始合成练习，在练习室检查日期、证券与虚拟本金，确认方案后创建。查看行情和持仓，预览并确认模拟订单，再推进到下一交易日查看成交；无模型也可操作。五年合成演示始终标明非真实行情。

控制室集中管理模型、数据、策略、权限与存储。普通Agent问答只提供建议和待确认草稿。有限自动模拟需单独保存授权并点击启动，证券、日期、步数、单笔金额和持仓上限均受约束，下单和推进分别授权；最多20步，可暂停或撤销。后端重启后保持暂停，核对状态并明确恢复后才继续。它由确定性算法执行，不代表模型自主交易。

真实历史取数、可模拟资格和当前报价是不同能力；本次只完成合成主线验证，新版真实模型联调及真实数据资格仍未完成，当前报价尚未提供。下文保留既有工作台与历史功能的详细说明。

# 历史模拟入门

本指南带你用明确标注的合成数据练习一次历史模拟。模拟只用于学习操作和理解记账，不连接券商，不会下真实订单，也不能证明一种策略能盈利。

## 三件彼此独立的事

- **行情数据**告诉模拟器某个日期有哪些价格。合成示例由本地程序生成，不需要行情 Token；真实历史数据必须先由支持的数据来源准备，并单独检查覆盖、资格和时点限制。获取失败不会自动换成合成数据。
- **历史模拟**把选定数据版本固定在一个隔离的模拟空间里。它不会改写个人账本。页面显示的日期是已经揭晓的信息；推进一次只揭晓服务端允许的下一交易日。
- **模型服务**是可选的。没有模型时，你仍能手动创建模拟、看行情、预览和确认模拟订单、推进日期并查看报告。配置模型也不会让 Agent 自动下单；草稿仍需你检查并在业务表单中确认。连接兼容服务可能产生费用，实际费用由服务商决定。

## 练习流程

1. 在“模拟工作台”点击“准备内置演示”，载入本地隔离的合成数据版本；不需要行情 Token 或模型 Key。也可以展开“高级数据准备”选择服务端支持的数据源和范围，该流程准备的是独立数据集样本，并非内置演示。
2. 按“数据与区间 → 本金与持仓 → 确认摘要”三步创建：选择数据版本和日期，设置模拟本金与可选期初持仓，核对摘要后点击“确认并创建模拟”。前两步只保留页面草稿，不创建模拟。金额以元显示、后端以整数分保存；持仓数量以股计。
3. 查看当前已揭晓日、现金、持仓、可卖数量和报价。报价缺失时页面会保留未知状态，不会把它当作零元。
4. 选择买入或卖出，先看预览中的数量、预计执行日、费用、滑点及阻断原因，再确认提交。预览不等于成交。规则、行情或可卖量证据不足时，系统可能拒绝或限制订单。
5. 成交通常依据下一可执行交易日的开盘参考价并按版本化不利滑点模型处理。逐日推进会揭晓下一个交易日；普通读取不会推进日期。
6. 查看同一已揭晓日期的四条对照路径，以及服务端复盘中的净资产、费用、收益和回撤。图例可用键盘切换，数据表提供文字替代；缺少估值时保留断点或 `null`，受限路径会说明原因。旧 revision 使预览失效时，草稿仍保留供你重新核对。对照差异不是交易因果证明。

### 内置演示和受限合成样本

“准备内置演示”提供固定的离线合成行情和对应模拟规则。后端回归用例覆盖了从该演示创建模拟后，用户手动提交的 100 股订单由模拟成交引擎成交；这是模拟账本中的成交，不是券商订单或真实交易。高级数据准备区中的合成数据是另一条数据集准备流程，资格和范围可能受限；它不保证可交易。即使内置演示中的用户订单可以成交，系统路径仍受其股票池快照和日期限制，不能据此承诺所有系统路径都有可用证券。

### 一个合成记账例子

假设练习账户有 ¥10,000 现金，在示例规则下买入 100 股、每股 ¥10 的证券。成交名义金额是 ¥1,000。基线合成费用规则包含单边佣金万分之五、每单最低 ¥5，买入过户费万分之一，以及不利滑点万分之十：佣金 ¥5、过户费 ¥0.10、滑点 ¥1.00，现金减少 ¥1,006.10，剩余 ¥8,993.90。此数值仅说明计算方法；实际订单仍受可用报价、股数规则、费用组合和模拟成交结果约束，不能把它当成真实券商收费。

## 报告里的词

- **现金**：当前可用模拟现金，单位元；服务端持久化整数分。
- **持仓 / 可卖数量**：当前持有股数，以及规则允许卖出的股数。新买入批次受 T+1 可卖限制；锁定、停牌、涨跌停或证据不足也可能减少可卖数量。
- **已揭晓日 / 下一执行日**：已揭晓日是模拟当前可见信息截止日；下一执行日是服务端规则确定的下一可执行日期，不保证等于下一个自然日。
- **净资产（NAV）**：现金 + 持仓估值 + 已确认应收 − 应付。若持仓缺估值或分红税后金额未确认，完整 NAV 和收益可能为未知，而不是把缺失值补成零。
- **扣费收益**：收益基于实际记录的模拟成交和费用。系统按完整估值计算区间收益，非模拟账户的外部入金/出金会调整分母；模拟段没有外部现金流。规则费用和滑点是版本化模拟假设，不是历史真实券商费率。
- **最大回撤**：报告把有效区间收益连乘成累计指数，并计算相对此前峰值的最大跌幅。若区间有未知收益，累计收益和最大回撤会保持未知。
- **比较路径**：用户操作、渐进调整、独立目标及持有不动。它们可能因行情资格、约束或缺数据而受限；系统路径不是已执行订单，也不能据此断言策略优劣。

## 研究与 Agent

复盘中的“发送给 Agent”只会把问题预填到 Agent 任务台并展开该面板，不会立即发送请求。要创建任务，先配置模型服务，再读取本次外发披露，核对目标、数据类别、用途和预算，勾选同意后显式提交。Agent 可在这些步骤完成后调用配置的模型和允许的工具；任务保留真实工具事件、用量、证据引用、停止原因和草稿，不展示隐藏思维链。交易或模拟条件草稿只会带你回业务表单，不会下单、推进日期或创建模拟；你仍须复核版本和内容并显式确认。

研究实验与模拟分离：先记录一个可检验改法，再读取上下文、冻结方案并核对训练区间、正式评估区间和累计预算，最后由用户显式启动。页面保留每次 attempt、失败/取消状态和 0 交易结果。技术字段收纳在详情中。反复查看同一数据会削弱“未见数据”解释；改版本标识不能清除已记录的数据曝光。默认 Agent 预算为最多 8 轮、20 次工具调用、120 秒、4096 Token；配置 Token 上限最高为 8192，单任务覆盖值只能调低配置上限。未知 Token 数或费用会显示未知；取消也不退还已发生的服务商费用。

真实模型调用尚需兼容服务和用户自行提供的配置才能验收。模型未配置、连接失败或任务受限时，手动模拟流程仍可使用；没有模型时不会出现假的 Agent 任务、进度或结论。接口替身只验证软件状态与工具契约，不证明真实模型效果。

## 控制室中的存储与受控观察

控制室会显示后端返回的存储分类、预算和准备状态。预算使用 GB 输入；固定保留区间可添加或移除，保存策略本身不会删除数据。清理前先读取候选与受保护原因，只有点击确认并在确认框再次确认后才请求服务端清理；引用冲突或预览过期时刷新并重新预览。

受控观察从练习记录选择练习，证券和日期会从记录预填。算法来自服务端注册表，参数按实际接口提供；未知扩展参数放在高级 JSON 区域。保存只登记有界计划，开始/继续、暂停和撤销分别操作；运行中只轮询状态，遇到读取失败需手动刷新。数据准备结果显示历史日期与来源，完成只表示准备任务完成，资格仍以服务端结果为准；历史区间不代表当前行情。模型配置中的服务 API URL 与模型名称应按兼容服务商给出的地址和标识填写，保存密钥时留空表示保留既有配置。

## 数据和能力限制

真实历史的来源许可、覆盖范围、历史股票池、上市/退市及停牌状态、严格历史发布时间资格可能不完整，页面会显示资格限制。公司行为目前只支持证据充分的现金分红及送转流程；复杂配股、合并和退市处置不推测。内置演示和高级合成样本都不是投资或策略有效性的证据；高级受限合成样本可能不满足订单或系统股票池资格。

## 备份与恢复

恢复前先停止正在运行的本地实例。恢复命令的 `--to` 接收一个新的 runtime 根目录，而不是数据库文件路径；主数据库位于新目录下的 `data/app.db`。例如：

```powershell
$env:APP_RUNTIME_DIR = [IO.Path]::GetFullPath('.runtime-restored')
$env:APP_DB_PATH = Join-Path $env:APP_RUNTIME_DIR 'data\app.db'
backend\.venv\Scripts\python.exe -m app.data.cli restore --from .runtime\backups\<备份包> --to $env:APP_RUNTIME_DIR
scripts\start-local.ps1
```

目标目录必须是新的空路径，恢复不会覆盖当前 runtime。v2 备份把主库还原到 `data/app.db`；兼容的 v1 备份也会把数据库放到该位置，并按旧格式还原 raw/archive 文件。恢复不包含模型凭据，请在本机重新配置 Key。切换回默认 runtime 前，先停止实例，再清除 `APP_RUNTIME_DIR` 和 `APP_DB_PATH`。
# 控制室：存储与受控观察

控制室的“存储与策略”区读取后端报告的分类占用、预算、可准备状态和固定区间。未知占用会显示为未知；设置预算不会删除数据。清理前先生成只读预览，查看候选版本与受保护版本，再显式确认；服务端会在删除前重新核对引用。过期或变化的预览需重新读取。

受控观察仅可选择后端注册的算法版本。先填写练习编号、证券范围、最多步数、单笔金额、持仓上限和截止日，分别勾选观察、模拟下单和日期推进权限，并保存计划。保存本身不启动；“明确开始”才调用服务端执行。刷新可读取已有计划；状态未知时先刷新核对，不要重复提交。暂停、撤销和继续均通过后端权限接口。普通手动下单与推进仍在练习室分别确认。

算法列表来自服务端真实注册表；若没有算法可用，无法创建计划。执行事件、停止原因和权限边界以服务端返回为准。任何模型或行情失败都不会自动改用合成数据。
